# Third-Party Components

AgenticSeg-RL includes or adapts code from open-source projects. Copyright notices in source files remain in effect.

- **veRL**: distributed reinforcement learning infrastructure. Apache License 2.0. <https://github.com/volcengine/verl>
- **EasyR1**: reinforcement learning training patterns used by the surrounding stack. Apache License 2.0. <https://github.com/hiyouga/EasyR1>
- **Segment Anything 2**: segmentation model integration and configuration. Apache License 2.0. <https://github.com/facebookresearch/sam2>
- **Hugging Face Transformers, PEFT, and TRL**: model, adapter, and reinforcement learning utilities. Apache License 2.0.
- **vLLM**: high-throughput rollout inference. Apache License 2.0.
- **Ray**: distributed execution. Apache License 2.0.
